# 📌 Sobre o Projeto

O **Fleet Management System (FMS)** é uma aplicação web desenvolvida para o **gerenciamento e controle de frotas corporativas**.

O sistema centraliza informações relacionadas a:

- 🚗 Veículos;
- 👨‍✈️ Motoristas;
- 🔧 Manutenções;
- 📄 Ordens de serviço;
- 📑 Contratos;
- 👥 Usuários;
- 💰 Custos;
- 📊 Indicadores operacionais.

A aplicação utiliza uma arquitetura **Full Stack**, integrando **Front-end, Back-end, API e banco de dados**.

A proposta é transformar processos de gestão de frotas em uma **solução digital estruturada**, facilitando a organização das informações, o acompanhamento da operação e a visualização dos principais indicadores.

# 💡 Motivação

Este projeto nasceu da união entre minha formação em **Análise e Desenvolvimento de Sistemas** e minha experiência profissional nas áreas **administrativa, de manutenção e gestão de frotas**.

Atualmente atuo diretamente com **manutenção de frotas** e, durante minha rotina profissional, identifiquei processos que poderiam ser mais estruturados, integrados e acompanhados por meio de uma solução tecnológica.

A partir dessa percepção, transformei uma necessidade observada no ambiente profissional em um **projeto de software**, utilizando conhecimentos de tecnologia para propor uma solução para um contexto real de negócio.

O **Fleet Management System** representa a união entre:

> **Experiência profissional + conhecimento de negócio + análise de dados + tecnologia.**

A proposta é demonstrar como conhecimentos adquiridos em diferentes áreas podem ser utilizados para **identificar problemas reais, compreender necessidades e transformá-las em soluções tecnológicas**.
